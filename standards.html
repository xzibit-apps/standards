Xzibit App Standard

Design system for every Xzibit app — tokens, components, and rules in a single stylesheet. Tied to Brand System v2.0, ConnectTeam-leaning, light-canvas, humanist, pragmatic.

Stylesheet tokens.json CLAUDE.md

1 · Install

Add one line to every Xzibit app. The stylesheet ships Inter, the full token set as CSS variables, and every component class. Nothing else needed.

<link rel="stylesheet" href="https://[YOUR-HOST]/xzibit-design.css">

Swap [YOUR-HOST] for wherever the stylesheet is hosted (e.g. standards.xzibit-apps.vercel.app).

2 · Principles

Six rules. If a design decision breaks any of these, the decision is wrong.

  • ✓Light canvas everywhere. White or #F8FAFC. Never dark-mode-default.
  • ✓Teal #19B1A1 is the only brand accent. Primary buttons, active nav, focus rings.
  • ✓Inter is the only font. Sentence case for every heading.
  • ✓Six-pastel status family (mint / sky / amber / coral / lilac / sun) for chrome. Charts may extend.
  • ✓Radii and spacing snap to tokens. No arbitrary pixels.
  • ✓Dashed outlines for emptiness, pastel + coloured left-border for events.

Before you ship

Run this against every new build. If anything is missing or wrong, fix it before publishing.

  • ✓Stylesheet <link> to xzibit-design.css is the first CSS loaded.
  • ✓Canvas is white or #F8FAFC. Sidebar is white with 1px hairline right border.
  • ✓Inter is the single font. No League Spartan in body copy.
  • ✓Headings are sentence case. No ALL CAPS except small .step eyebrow labels.
  • ✓Teal #19B1A1 is the single brand accent — primary button, active nav, focus rings.
  • ✓Status uses the six-pastel family only. No bespoke reds, greens, blues in chrome.
  • ✓Shift blocks use 4px coloured left border + pastel-50 fill + 10px radius.
  • ✓Empty slots are 1.5px dashed outlines that turn teal on hover.
  • ✓Buttons are pill-shaped. Primary has the soft teal shadow.
  • ✓All radii snap to tokens. All spacing snaps to the 4/8 ladder.
